# 🫁 Pneumonia Detection from Chest X-rays

**A 6-model deep-learning benchmark with trustworthy-AI analysis**: calibrated probabilities,
uncertainty-based referral to a radiologist, bootstrap confidence intervals and Grad-CAM
explanations, on two tasks: **Normal vs Pneumonia** and **Normal / Bacterial / Viral**.

[![tests](https://github.com/katalnishant/pneumonia-detection/actions/workflows/tests.yml/badge.svg)](https://github.com/katalnishant/pneumonia-detection/actions/workflows/tests.yml)

> ⚠️ Educational project. Not a medical device, not for clinical use.

## What's in it

| | |
|---|---|
| **Leak-free data split** | The official validation folder has only 16 images. Train + val are re-split **by patient** (`StratifiedGroupKFold`), so no person appears in both train and validation; the official test set is untouched. |
| **6 models** | Custom CNN · *VGG16 v1* (the original version of this project: frozen base + Flatten head) · VGG16 · ResNet50 · DenseNet121 (CheXNet's backbone) · EfficientNetB0, all fine-tuned in two phases (frozen backbone → unfreeze last block, BatchNorm kept frozen, LR 1e-5). |
| **2 tasks** | Binary, and 3-class bacterial vs viral (labels parsed from file names), on the same patient split. |
| **Ensemble + TTA** | Top-3 models ranked by *validation* AUC, averaged over 5 test-time views. |
| **Calibration** | Temperature scaling fitted on validation; reliability diagrams and ECE before/after. |
| **Uncertainty & referral** | MC-dropout (30 passes) or ensemble disagreement. The most uncertain 10% (cut-off chosen on validation) is referred to a radiologist, and we measure accuracy on the cases the model keeps. |
| **Statistics** | 95% bootstrap CIs (1,000 resamples) on every test metric. |
| **Explainability** | Grad-CAM on the backbone's last feature map. |
| **Engineering** | In-model preprocessing (no train/serve skew), cached data pipeline, resumable pipeline, unit tests + CI, Streamlit app. |

## Run it

**Kaggle (free GPU):** import `notebooks/pneumonia_kaggle.ipynb`, add the dataset
[`paultimothymooney/chest-xray-pneumonia`](https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia),
set GPU + Internet on, *Save & Run All* (~2–3 h).

**Locally:**
```bash
pip install -r requirements.txt
export PNEUMO_DATA=data/chest_xray          # unzipped Kaggle dataset
python -m src.pipeline                      # everything: both tasks, all models
python -m src.pipeline --tasks binary --models cnn densenet121 --quick   # smoke test
python -m pytest -q tests
```

**App** (needs `artifacts/` from a run, e.g. the Kaggle `artifacts.zip`):
```bash
streamlit run app/streamlit_app.py
python -m src.inference path/to/xray.jpeg --task multiclass
```

## Project structure
```
src/
  config.py     hyper-parameters, paths, model list
  data.py       patient-level split, label parsing, cached arrays, tf.data + augmentation
  models.py     model zoo, in-model preprocessing, two-phase fine-tuning
  train.py      training with checkpoints / early stopping / LR schedule
  predict.py    plain, TTA and MC-dropout predictions on val + test
  analyze.py    calibration, thresholds, ensemble, bootstrap CIs, referral, figures, tables
  gradcam.py    Grad-CAM for every architecture
  inference.py  single-image prediction with calibration + referral (used by the app)
  pipeline.py   runs everything end to end (resumable)
app/streamlit_app.py
notebooks/pneumonia_kaggle.ipynb    (generated by scripts/build_kaggle_notebook.py)
tests/test_core.py
```

## Method notes
- **Input:** 224×224 grayscale replicated to 3 channels. Augmentation: ±10° rotation, zoom, shift and
  contrast. **No horizontal flips**, because the heart sits on the left and a mirrored X-ray isn't anatomically realistic.
- **Imbalance:** class weights (except VGG16 v1, which keeps its original recipe), model selection on
  validation ROC-AUC rather than accuracy.
- **Binary decision threshold:** Youden's J on calibrated validation probabilities.
- **No test-set peeking:** thresholds, temperatures, referral cut-offs and ensemble members all come
  from validation.

## Limitations
Single-centre pediatric dataset (Guangzhou, ages 1–5); known label noise; the test set's class balance
differs from training's; Grad-CAM shows correlation, not causation. External validation (e.g. on RSNA
Pneumonia) is the natural next step.
